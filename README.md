# BankingPortal-API

## Overview
BankingPortal-API is a secure and scalable banking management system built using Java, Spring Boot, and MySQL. It provides RESTful APIs for managing user accounts, transactions, and fund transfers with strong security and reliable performance.

## Features
- User Registration and Login
- JWT-Based Authentication & Authorization
- Account Management
- Balance Inquiry
- Fund Transfer between accounts
- Transaction History tracking
- Role-based access control (Admin/User)
- Exception handling and input validation

## Technology Stack
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- RESTful API
- JWT Authentication
- Maven

## Project Goal
The goal of this project is to simulate real-world banking operations by building a secure backend system with proper authentication, clean architecture, and efficient database handling.
